# Project Overview - HarleyStore

## 1. Visão Geral
Sistema de e-commerce e gestão para a loja HarleyStore.

## 2. Problema
Necessidade de centralizar a gestão de produtos, clientes e pedidos numa plataforma única e intuitiva.

## 3. Objetivos
Oferecer uma interface fluida para os clientes e um painel de controlo eficiente para a gestão do catálogo e das vendas.

## 4. Arquitetura Tecnológica
- **Frontend:** Reflex (tecnologia exclusiva para a interface de utilizador)
- **Backend:** Xano (gestão de lógica de negócio e persistência via APIs)
- **Linguagem do Projeto:** Python

## 5. Princípios de Desenvolvimento
- Mudanças incrementais geridas via OpenSpec.
- Separação clara entre frontend (Reflex) e regras de negócio no backend.
